# ToolNest — DIY & home-improvement storefront

A fast, installable (PWA), fully responsive e‑commerce front end that feels like
a native Android app. Static site → deploys free to **GitHub Pages**, with an
optional **Google Sheets** backend for accounts and orders.

> **Branding is a placeholder.** The store name, logo and colours are generated
> originals (`ToolNest`). Swap in your own brand in one place — see below.
> This project is **not** affiliated with or a copy of any real retailer; all
> product data and imagery are original placeholders generated by the app.

## ✨ Features
- Home with hero, top selection, best‑sellers, category grid, brand strip
- Category / search / deals listing with **sort + filters** (price, type, brand)
- Product detail with quantity, add‑to‑basket, buy‑now, related items
- Basket with live totals, quantity edit, checkout
- **Auth**: register / log in with **email _or_ mobile** + password
  (password **hashed on-device**, never stored in plaintext)
- Account page with order history
- **USD** pricing throughout
- **All images generated in-app as inline SVG** — nothing is hotlinked from
  another website
- PWA: installable, offline app‑shell, bottom tab bar, safe‑area aware

## 🧱 Tech
Plain HTML/CSS/JS (no build step). Google Apps Script + Google Sheets backend
(optional). Service worker for offline.

## 🎨 Make it yours (brand)
Edit **`js/config.js`**:
```js
BRAND_NAME: "YourStore",
BRAND_SHORT: "YourStore",
BRAND_TAGLINE: "Your tagline",
```
Optionally replace `images/icon.svg` with your own logo (keep the filename).
That’s it — the name, header, footer, PWA and “Choice” label all follow.

> Also update the human‑readable `<title>` text in the `.html` files if you want
> the browser tab to show your brand (optional; purely cosmetic).

## 📦 Products
The catalog lives in **`data/products.json`** (seeded sample). Edit/add items
there, or load them into Google Sheets and manage them from the sheet
(see `apps-script/README.md`). Each product supports an optional `imageUrl`
pointing at a **local** image in `images/` if you’d rather use real photos;
otherwise a clean SVG placeholder is generated automatically.

## 🚀 Deploy to GitHub Pages (`https://manomano-arch.github.io`)
This repo is set up to publish from the repo root.

### Option A — user/organization site (root domain)
1. Create a repo named **`manomano-arch.github.io`** under the `manomano-arch`
   account.
2. Push this project to the `main` branch (files at the repo root).
3. Repo **Settings → Pages → Build and deployment → Source: Deploy from a
   branch → `main` / `/ (root)`**. Save.
4. Visit `https://manomano-arch.github.io` in ~1 minute.

A workflow at `.github/workflows/deploy.yml` is also included if you prefer
GitHub Actions deployment (**Settings → Pages → Source: GitHub Actions**).

### Local preview
```bash
cd Ecom_project
python3 -m http.server 8080
# open http://localhost:8080
```
(Use a server, not `file://`, so the service worker and fetches work.)

## 🔌 Connect Google Sheets (optional but recommended)
See **[`apps-script/README.md`](apps-script/README.md)** — create a sheet, paste
`Code.gs`, deploy as a Web App, paste the URL into `js/config.js → API_URL`.
Until you do, the site runs fully from local JSON + on‑device storage, so it
works the moment it’s deployed.

## 🔐 Security notes
- Passwords are hashed with SHA‑256 (+ app pepper) in the browser; only the hash
  is sent/stored. This is **demo‑grade** — fine for a portfolio, not a bank.
- Don’t put secrets in this repo; everything here is public once on Pages.
